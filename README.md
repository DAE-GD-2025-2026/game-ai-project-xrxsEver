# Algorithm 2 - Unreal Project

Assignment for the **Algorithm 2** course at **DAE (Digital Arts and Entertainment)**.

## About

This Unreal Engine project explores various AI programming concepts, including:

- **Steering Behaviors** — seek, flee, arrive, wander, pursuit, evade, etc.
- **Combined Steering** — blending and prioritizing multiple steering behaviors
- **Flocking** — separation, alignment, and cohesion for group movement
- **Spatial Partitioning** — efficient neighbor queries for large numbers of agents

## Project Structure

- `Source/` — C++ gameplay and AI code
- `Content/` — Blueprints, levels, and assets
- `Content/Levels/` — Individual levels for each topic (CombinedSteering, Flook, GraphTheory, etc.)
